# disturbance_compare — committed evidence (drift#67)

Written by `data-raw/disturbance_compare.R`. Read
[`inst/notes/temporal-qa-disturbance.md`](../../../inst/notes/temporal-qa-disturbance.md) first;
this directory is what that note quotes.

## Committed, per group (`bulk/`, `necr/`, `lnth/`, `kotl/`)

| file | what it is |
|---|---|
| `summary_events.csv` | the sample, written BEFORE any agreement number: tagged patches and area by (source, year), each year classed `full` / `partial` / `none` for whether it can discriminate a disturbance-driven break from endpoint noise, plus distinct `fire_number` where an id is published |
| `summary_reconcile.csv` | drift's change patches -> published layer, one row per named mechanism, deltas summing exactly |
| `summary_class_compare.csv` | per-transition-class reproduction against the published layer — the assertion that matters, since a matching total with mismatched classes is a different pipeline agreeing by luck |
| `join_audit.csv` | proof the `patch_id` join is lossless: zero-cell patches, cells x cell area against geometry area, published ids matched |
| `summary_break_offset.csv` | `break_year - disturbance_year`, full distribution by (source, disturbance year, offset). A tagged patch with no clean break gets a row with `offset = NA`, so the agreement rate's two denominators come from one population |
| `summary_flicker_strata.csv` | flicker and clean-break fraction for harvest-touching / fire-touching / untagged-residual, in each of four geometric strata |
| `group_meta.csv` | grid, CRS, the sieve constant, the derived discriminating years, published vs running drift version, the sub-basin file and its md5, the pass/fail of the reconciliation, and `script_sha` + `run_started` -- `summarize` refuses unless all four groups carry the same `script_sha`, which is what stops a note being assembled from two definitions of one measurand |
| `timings.csv`, `rss.txt`, `run_wallclock.txt` | the run record |

## Committed, here

`summary_reconcile_groups.csv`, `summary_events_groups.csv`, `summary_agreement_groups.csv`,
`summary_events_disc_groups.csv`, `summary_flicker_groups.csv` and `summary_groups.md` — the
note's tables. `summary_groups.csv` is the reconciliation summary and doubles as the stage's
**completion marker**: it is written last, after the note check, so its presence means the whole
stage ran. The `summarize` stage refuses to finish if the note's copy of `summary_groups.md`
differs — proven to fire on a one-digit mutation and to pass when restored.

## Not committed (gitignored)

The downloaded `classified_<year>.tif`, `floodplain.gpkg`, `transition_vector.gpkg`, `item.json`
and `run.log`, and `summary_patch_join.csv` (one row per change patch). All are regenerated by
re-running; the COGs and GeoPackages are verified against each asset's published `file:checksum`
on the way in.

## Re-running

```bash
bash data-raw/disturbance_compare-run.sh bulk necr lnth kotl
Rscript data-raw/disturbance_compare.R summarize
```

One machine-local input is **not** published and is required for the exact reconciliation:
`~/Projects/repo/floodplains/data/<group>/subbasins.gpkg`, a floodplains step-2 product,
gitignored there. Its path and md5 are recorded in each `group_meta.csv`; without it the script
stops with a message saying so rather than silently substituting a different zone.

Peak RSS 14.1-16.9 GiB on a 64 GB machine for grids of 56M-204M cells — terra sizing to available
RAM, not a per-group requirement. See #69 for the `dft_rast_transition()` intermediates that make
it higher than it needs to be.
